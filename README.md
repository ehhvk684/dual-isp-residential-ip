## 双ISP住宅IP到底改了什么：从 ASN 说起

### 平台查的不是你的服务器放在哪

很多人以为买个"东京机房"的 VPS，IP 显示东京，平台就会当成日本用户。实际风控看的是 IP 的 ASN 归属和类型标记：这段 IP 是注册在 AWS、阿里云、Vultr 这类 hosting 网络下，还是注册在本地宽带运营商名下。

机房段的 IP 有一个共同特征——整段地址被批量标记为数据中心用途。平台不需要知道你是谁，只要看到 ASN 归属是云服务商，信任分就直接降一档。这就是为什么同样是日本 IP，有人能正常刷日区 Netflix，有人一开就提示"内容不可用"。

住宅 IP 的逻辑正相反：它的 ASN 挂在本地宽带运营商名下，IP 类型被标记为家宽。平台看到的不是一台服务器，而是一个住在当地的普通宽带用户。

"双 ISP"是在这之上再加一层。同一个 IP 在两家不同运营商的登记信息里都指向家庭宽带，风控模型做交叉验证时，很难把它归到机房那一类。你可以把它理解成地址证明：一份水电单可以伪造，两份不同来源、互相能对上的账单，审核方基本就不追问了。

### 四类最典型的用法

**TikTok 运营**。这是需求最大的一块。TikTok 对 IP 纯净度极其敏感，机房 IP 经常表现为零播放、限流、账号地区乱跳。住宅 IP 能让账号的"本地用户"身份站得住。

**AI 工具**。ChatGPT、Claude、Gemini 对数据中心 IP 有明确的识别机制，机房段经常直接拒。住宅 IP 走的是普通家庭宽带出口，被拦的概率低得多。

**跨境电商与社媒多账号**。亚马逊、eBay、Shopify 注册和养号阶段都会查 IP 归属，Facebook、Instagram、WhatsApp 的多账号管理更是把 IP 环境当基础设施。

**流媒体与本地化服务**。Netflix、Disney+、DMM TV、Abema TV、动画疯这类按地区授权的内容，对 IP 的"本地属性"要求比一般网站严格。

有一点必须提前说清楚：住宅 IP 不是万能护身符。账号能不能活，还跟设备指纹、行为模式、支付方式有关。重要账号建议先月付、低频使用一周以上，观察登录和 API 调用有没有异常，再决定要不要长期持有。

## 必须先知道的限制与不适合的人

这部分不打折扣地说。

**入门款硬盘只有 10G。** 装个系统加基础环境就占掉一半，建站、跑数据库、存素材都不够。要拿来做这些，直接看 40G 起的标准档。

**带宽配额收紧，不适合大流量业务。** 视频搬运、大文件下载、做 CDN 回源这类用法，流量很快见底，超了要么限速要么加钱。这类需求本身也不该用住宅 IP，成本结构不匹配。

**美国部分 IP 段联通去程拥堵。** 38 段、154 段、209 段的 COGENT 线路曾经出现过中国联通去程拥堵，电信和移动用户不受影响。联通用户下单前问一下客服当前 IP 段情况；如果已经开出来了，有第三方提到可以提工单申请换到 NTT/GTT 的 70、64、192、216 段，这条没在官方页面确认，属于经验性做法。

**日本两条线都不是大陆直连优化。** 需要经香港或日本中转，并开启 BBR。想拿它做大陆访问的低延迟建站，方向就错了。

**退款是 48 小时内，住宅 IP 类只退网站余额。** 官方在部分产品页明确写了"特殊产品，退款仅退网站余额"。也就是说钱退回账户里，不是原路返回银行卡。另外，服务大量使用（带宽超分配 5% 或 20GB，取较小值）、有滥用行为、或产生安装费/支付处理费的情况不在退款范围；48 小时后申请按个案处理。用 USDT 支付的，退款同样只到账户余额。

**英文客服响应有限。** 团队主要面向中文用户，全中文界面是优点，反过来英文沟通效率就一般。

**不适合的人**：想要一台便宜大盘鸡做存储的、想要大陆直连低延迟建站的、想要无限流量跑下载的、以及希望一个 IP 挂十几个账号的——最后这条尤其要说明，套餐默认 1 个 IPv4，多账号就该一账号一 IP，硬塞在一起，IP 再干净也会因为行为关联被串起来。

## 常见问题

**双ISP住宅IP和普通住宅IP差在哪？**
普通住宅 IP 只在一个运营商的登记信息里是家宽属性；双 ISP 是两个运营商的记录都指向家庭宽带。风控做交叉验证时，后者的可信度更高，也更难被批量标记。

**一个 IP 能挂几个账号？**
套餐默认 1 个 IPv4。多账号建议一账号一 IP，同一 IP 下多个账号的行为关联，比 IP 本身更容易触发风控。真要多账号，看独立服务器方案。

**能用来建站吗？**
技术上可以，KVM 架构、NVMe 硬盘、支持装 Windows。但入门款 10G 硬盘和偏紧的流量配额不适合正经站点，至少上到 40G 档，而且美国、日本线都不是为大陆访问优化的。

**能支付宝付款吗？**
可以，全中文界面。另外支持 USDT，但 USDT 支付的退款只退到账户余额。

**退款怎么退？**
开通 48 小时内可申请，住宅 IP 类特殊产品只退网站余额，不是原路退回。超过 48 小时按个案处理，且需放弃该时段之后的退款权利。

**优惠码在哪填、续费还有效吗？**
结账页的优惠码输入框，填入 `TS-CBP205DQJE` 后点应用自动重算。这是循环优惠，续费同样 9 折。
